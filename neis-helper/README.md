# 담임 기록 → 나이스 입력 도우미 0.3.29

## 한 학생씩 자동입력

1. 앱에서 확인한 출결 기록을 선택하고 **선택한 기록 보내기**를 누릅니다.
2. 같은 Chrome의 나이스에서 해당 **반의 출결표**를 엽니다. 날짜는 도우미가 바꾸며 조회 버튼을 추가로 누르지 않습니다. 열린 출결마감구분 팝업은 닫습니다.
3. 확장 프로그램 패널에서 **학생 · 날짜 선택 → 학생 찾아 자동입력**을 누릅니다.
4. 날짜 선택 → 이름·번호·반·날짜 대조 → 학생 행 선택 → 마감 창 열기 → 종류·구분·사유 입력 → 적용 → 기준 교시 클릭 → 표시 확인을 진행합니다.
5. 나이스의 실제 값이 맞으면 **나이스 저장 버튼**을 직접 누릅니다. 저장 결과를 확인한 뒤 패널의 저장 확인을 체크합니다. 앱을 열면 완료한 날짜가 자동 반영되어 입력 대기함에서 빠집니다. 남은 날짜만 다시 내보냅니다.

지각은 마지막 빠진 교시를 클릭해 조회부터 해당 교시까지 포함합니다. 조퇴는 처음 빠진 교시를 클릭해 종례까지 포함합니다. 월·금 7교시, 화·수·목 6교시를 사용합니다. 결석은 조회부터 종례까지 전체 표시를 확인합니다. 결과·외출과 주말 수업은 자동입력하지 않습니다.

선택한 학생·날짜의 기존 종류·구분·사유를 새 기록으로 덮어씁니다. 적용 후 교시 전체가 새 기록과 일치해야 입력 완료로 표시합니다. 이미 같은 내용이 모두 표시된 경우에는 다시 클릭하지 않습니다. 날짜·학생·열을 확실히 찾지 못하면 입력을 시작하지 않습니다. 적용 이후 확인 실패는 일부 내용이 남았을 수 있음을 안내하고 완료나 저장으로 표시하지 않습니다.

**선생님이 제공한 DOM 구조와 일치하는 가상 화면 테스트를 통과했지만 실제 나이스 PC 검증은 아직 남아 있습니다.** 첫 한 건의 화면 결과를 확인한 뒤 계속 사용하세요. 공식 나이스 API나 무인 일괄 저장 방식은 아닙니다.

## 설치 및 업데이트

처음 설치: ZIP 압축 풀기 → Chrome 주소창 `chrome://extensions` → 개발자 모드 → 압축해제된 확장프로그램 로드 → manifest.json이 있는 폴더 선택.

기존 사용자는 새 ZIP 내용을 기존 도우미 폴더에 덮어쓰고, 확장프로그램 카드의 동그란 새로고침 화살표를 누릅니다. **나이스와 기록함 탭도 새로고침**해야 이전 스크립트가 교체됩니다. 카드 버전이 0.3.29인지 확인하세요.

## 직접 입력 및 복사

패널의 **직접 입력 · 복사**를 펼치면 기존 도우미 기능을 이용할 수 있습니다.

- 열린 창만 채우기: 학생·날짜 확인 → 종류·구분·사유 자동입력. 적용·교시·저장은 자동 실행하지 않습니다.
- 한 항목씩 입력: 넣을 값 선택 → 입력칸 선택 → 실제 입력칸 클릭 → 선택한 입력칸에 넣기.
- 각 항목의 복사 버튼도 사용할 수 있습니다.

## 자료 처리

외부 서버 전송, AI 호출, 로그인 정보 수집을 하지 않습니다. HTTPS `neis.go.kr` 및 하위 도메인만 대상으로 동작합니다. 앱 직접 전달은 `https://class-calendar-beryl.vercel.app`에서만 받습니다. 기록과 진행 상태는 Chrome의 세션 저장소에 보관하며 브라우저 종료 시 지워집니다. 앱의 원문·첨부·교사 메모는 가져오지 않습니다. 별도로 내려받은 JSON 파일은 PC에 남습니다.

화면 좌표나 임의 UUID를 고정하지 않습니다. 표 머리글과 셀의 위치를 대조하며, 동일 이름은 번호까지 확인합니다. 학생이 가상 스크롤 밖에 있으면 화면에 보이도록 스크롤한 뒤 다시 시도합니다. 반 자동 이동과 최종 저장은 수행하지 않습니다. 날짜 입력칸이 유일하고 편집 가능할 때만 날짜를 변경하며, 표의 반·날짜 제목이 갱신된 뒤 학생을 선택합니다.

## 개발

프로젝트 루트에서 `npm run check`로 검증하고 빌드합니다. `node scripts/package-neis-helper.mjs`로 ZIP을 생성합니다. ZIP에 테스트·학생 자료·외부 라이브러리는 넣지 않습니다.

Chrome 공식 문서: https://developer.chrome.com/docs/extensions/reference/api/sidePanel · https://developer.chrome.com/docs/extensions/reference/api/scripting · https://developer.chrome.com/docs/extensions/reference/api/storage

완료 확인은 앱의 서버 저장에 성공한 뒤 도우미가 수신 확인을 받습니다. 새 입력 대기를 받아도 미동기화 완료 내역은 유지합니다. 기존 기록 내용과 학생·날짜가 달라진 경우에는 이전 완료 내역을 적용하지 않습니다.

## 달력 클릭
열린 cl-calendar-field 달력에서 이전달·다음달로 이동하고, 날짜의 연·월·일 aria-label을 대조해 클릭합니다. 다른 달 날짜는 제외합니다. 월 이동과 출결표 제목 갱신을 확인한 뒤 학생을 선택합니다. 날짜 입력칸 옆 달력 버튼의 라벨이 유일하게 식별되면 자동으로 열고, 식별되지 않으면 기존 날짜 입력 방식을 유지합니다. 입력 방식이 동작하지 않는 화면에서는 달력을 열어 둔 뒤 자동입력을 누릅니다.

처음 열린 Total 0 빈 출결표도 지원합니다. 먼저 날짜를 바꾸고 표 갱신을 기다리며, 처음부터 빈 표가 갱신되지 않을 때만 유일한 조회 버튼을 한 번 누릅니다. 이후 반·날짜 제목과 학생 이름·번호를 반드시 대조합니다.

0.3.29는 실제 일자 입력칸 옆 버튼 라벨 ‘달력으로 날짜 선택’을 인식해 닫힌 달력을 먼저 엽니다. 증가·감소 버튼은 누르지 않으며 읽기 전용 일자 칸도 달력으로 선택합니다.

0.3.29: 기존 종류·구분·사유를 덮어씁니다. 나이스 저장 후 도우미의 저장 확인을 누르면 다음 미완료 학생·날짜를 자동 선택해 입력합니다. 실제 나이스 저장 성공을 자동 감지하는 기능은 포함하지 않습니다.

0.3.29: 자동입력 후 일일출결 저장 버튼을 누릅니다. 새 저장 성공 메시지와 학생 출결이 확인되면 앱 완료 상태를 반영하고 다음 학생을 입력합니다. 성공 메시지를 확인하지 못하거나 확인창이 뜨면 다음 학생으로 넘어가지 않습니다.

0.3.29: 저장 버튼 뒤 ‘저장하시겠습니까?’ 창의 확인을 한 번 누르고, 저장 성공 메시지를 확인한 뒤 다음 학생으로 넘어갑니다. 다른 종류의 확인창은 누르지 않습니다.

0.3.29: 변경된 내용이 없다는 알림은 학생·날짜·출결·사유·교시가 기록과 일치할 때 확인을 누르고 완료 처리합니다. 다음 미완료 학생으로 이어집니다.

저장했습니다 완료 알림의 확인도 누른 후 다음 학생으로 넘어갑니다.

0.3.29: 출결마감구분·교시 불완전 저장 오류는 확인을 눌러 닫고 미입력 상태로 남깁니다. 다음 학생을 계속 처리하고 마지막에 미입력 학생·날짜·사유 목록을 표시합니다.


## 학부모 신고서 접수
앱에서 기록을 보내고 작업을 학부모 신고서 접수로 선택하세요. 동일 학생·날짜·종류의 상세조회 창을 열고 열린 신고서 접수·저장을 누르면 구분·접수·시작/종료 교시·담임 사유를 채우고 저장을 클릭합니다. 저장 확인창은 직접 확인하세요. 접수 저장은 일일출결 입력 완료로 전달하지 않습니다.
